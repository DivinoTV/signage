# Kartu Front Desk

Cetak, potong, taruh di meja front desk tiap properti.

---

```
┌──────────────────────────────────────────────┐
│                                              │
│   TV INFORMASI KAMAR — RUTIN PAGI            │
│                                              │
│   1.  Nyalakan TV                            │
│   2.  Tekan  HOME                            │
│   3.  Pilih  INTERNET                        │
│   4.  Tunggu halaman muncul                  │
│   5.  Ikon  ⛶  muncul di sudut kanan        │
│       bawah — tekan  OK  sekali              │
│                                              │
│   Selesai. Tinggalkan begitu saja.           │
│                                              │
│   Tombolnya hilang sendiri setelah 30 detik. │
│   Kalau sudah hilang, tekan tombol arah      │

│                                              │

│                                              │

│                                              │
└──────────────────────────────────────────────┘
```

## Untuk yang memasang kartu ini

Isi nama dan kontak pelapor di baris kosong sebelum dicetak.

Kalimat "jangan dicoba diperbaiki" itu disengaja. Percobaan perbaikan yang paling sering
terjadi adalah mengetik ulang alamat pakai remote, dan itu justru merusak homepage yang
sudah benar — kerusakan yang jauh lebih lama diperbaiki daripada layar hitam biasa.

**Soal langkah 5.** Fullscreen menghilangkan toolbar browser Samsung yang menutupi bagian
atas layar. Ini harus ditekan manusia — aturan browser, halaman tidak boleh membuat
dirinya fullscreen sendiri, jadi tidak bisa diotomatiskan. Kalau langkah 5 terlewat,
tampilannya tetap benar dan tetap berganti slide, hanya ada toolbar di atasnya. Jadi ini
bukan hal yang bisa merusak apa pun kalau terlupa.

Tombolnya sengaja hilang setelah 30 detik supaya tamu tidak melihat tombol di kamarnya.

TV tidak menerima input dari tamu. Kalau ada remote yang hilang atau tombolnya tertekan
tamu, tampilan tidak akan berubah — paling buruk browsernya tertutup, dan itu selesai
dengan langkah 1–4.
